# Imagens da Clínica Veterinária

Coloque seus arquivos de imagem (como `bannerdesktop.png`, `bannermobile.png`, `pet01.jpg`, `pet02.jpg`, `pet03.jpg`, etc.) diretamente nesta pasta.

Ao fazer isso, os arquivos serão servidos de forma local e confiável através do caminho relativo, por exemplo:
`/imagens/bannerdesktop.png`

Isso evita que as imagens parem de funcionar caso o link do GitHub mude ou sofra instabilidade!
